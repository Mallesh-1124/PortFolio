# Mallesh Kolipaka - Portfolio

> A responsive developer portfolio for showcasing projects, technical skills, experience, research, and contact information.

## Live site

**[Open the live portfolio](https://mallesh-1124.github.io/PortFolio/)**

## About

This portfolio belongs to **Mallesh Kolipaka**, a Python-focused backend and full-stack developer. It presents selected work across web development, AI integrations, backend architecture, and embedded systems.

The site is designed to be fast, accessible, and easy to explore, with a responsive layout that works across desktop and mobile devices.

## Highlights

- Responsive dark/light portfolio interface
- Animated loading screen, custom cursor, scroll reveals, and typewriter introduction
- Project filtering and detailed project modals
- Live GitHub repository integration
- Downloadable resume and research publication links
- Client-side contact form with email handoff
- GitHub Pages deployment on every push to `master`

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub REST API
- GitHub Pages and GitHub Actions

## Run locally

This is a static site, so no build step or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Mallesh-1124/PortFolio.git
   cd PortFolio
   ```

2. Serve the directory with any local static server. For example:

   ```bash
   python -m http.server 8000
   ```

3. Open [http://localhost:8000](http://localhost:8000) in your browser.
